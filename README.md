## What I'm building

### StarForgedSMP

![StarForgedSMP](assets/starforged-banner.png)

The Minecraft network I'm developing: progression, claims, player markets, cosmetics
and shared systems across Survival and Creative, with Java and Bedrock crossplay.
Built with Kotlin, Paper, Velocity, PostgreSQL and Geyser/Floodgate. Development
source is private; the public community is at **starforgedsmp.net**.

[Join the community](https://discord.gg/sYRJK6XYzS)

### MayorSystem

A configurable Paper plugin for mayor elections, player voting and server-wide perks,
with administration tools, optional integrations and an addon API.

[Source](https://github.com/Louguerrier22/MayorSystem) ·
[Documentation](https://louguerrier22.github.io/MayorSystem/) ·
[Modrinth](https://modrinth.com/plugin/mayorsystem)
